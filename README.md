## 📂 Things I've built

### 🍜 [KhauBot — Hyperlocal AI Food Discovery](https://github.com/ketkivmohite/khaubot)
Mumbai's informal food economy, made searchable through natural language.
- **71+ production deployments** on Vercel — FastAPI + Django + PostgreSQL (Neon DB)
- Multilingual NLP pipeline (English / Hindi / Hinglish) powered by Groq LLM
- Extracts location, cuisine, and price intent from free-text queries

### 🏥 [AI CRM for Healthcare](https://github.com/ketkivmohite/ai-crm-healthcare)
Field reps describe doctor visits in plain English. The agent handles the rest.
- **LangGraph agent with 5 tools** — auto-extracts structured data, sentiment, follow-up actions
- React + Redux frontend, FastAPI + SQLAlchemy backend, Swagger-documented API

### 📚 [Hellobooks — RAG Q&A System](https://github.com/ketkivmohite/hellobooks)
Ask questions about accounting. Get answers grounded in real documents.
- FAISS vector store + SentenceTransformers + Groq LLM
- Containerised with Docker for clean, reproducible deployment

### 🎭 [Bharatanatyam Mudra Classifier](https://github.com/ketkivmohite/BharatNatyam-Mudra-classifier)
Classical Indian dance meets deep learning.
- Fine-tuned VGG19 achieving **~98% accuracy** on custom dataset
- V2 extended with error-detection on incorrect mudras
